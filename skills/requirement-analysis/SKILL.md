# 按需澄清

遵循目标项目规则及 [执行约定](../../workflow/execution-contract.md)。当前事项文档是唯一目标与进度来源，原生任务保留派发和结束事实；不创建机器业务账本、逐轮快照或版本目录。旧任务回原锁定包，不以本Skill解释旧权限。共享文档单写，返回结果由文档写入者合并。

先核实用户已有目标和相关实现，只问会影响实现/验收的缺失决策。已有授权和已回答问题不重复询问。小需求目标清楚即可执行，不强制再写需求稿和统一批准。

把必要目标、范围、可验证行为及确认结论写回当前文档，不复制原输入、完整对话或历史版本。用户补充沿用同事项入口，只有独立目标新建。范围/验收存在分歧或具体风险时按执行约定确认，不能借澄清扩大授权。

默认 [任务模板](../../templates/task.md)；复杂业务必要时补例外/失败行为，参考 [澄清指引](references/clarification.md)，不自动拆正式需求书。
