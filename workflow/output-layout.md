# 事项文档与成果

一次性局部低风险小修无需建文件；跨会话恢复、交接或多步持久跟踪确有需要时，只有 `<features_dir>/<事项名称>/task.md`，可使用 [任务模板](../templates/task.md)。正文包含目标、范围、勾选任务、验证和必要待办；它同时是人工入口及恢复入口，无额外README、status、events、input、documents索引或版本目录。

实际需要的设计稿、代码、交付文件按项目约定保存，由task.md引用；不为了角色齐全生成空文稿。必要失败证据保留在已有测试/日志位置，仅引用相关片段，不复制完整日志或基线到对话。共享内容不得泄露凭据。

跨角色保持文件单写，宿主原生任务已记录的事实不另建机器副本。历史目录和旧模板仅由原锁定版本读取，不批量搬迁、清理或重算。
