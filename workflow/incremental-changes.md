# 补充与续改

同一事项的补充、修复、重试和完成后续改始终更新 [同一协调入口及对应文档](revisions.md)。范围/验收有分歧先在对话确认，把结论写回所属需求或设计文档，任务入口摘要引用；没有新增分歧或风险时继续工作，不为每次增量重复审批。

先通知正在执行任务的另一角色，确认原调用状态及写入归属后调整任务；未知调用先恢复，不并发重派。旧范围的通过不覆盖新变化，重验受影响部分；真实失败记录保留，不能修改成通过。

不建立baseline_id、审批digest、授权版本、逐轮快照或新修订目录。确需避免验错内容时，只记录相关文件的版本或摘要。旧布局4任务仍由原锁定包处理，不套用本条删改旧记录。
