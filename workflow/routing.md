# 主动路由与按需协作

主会话对流程选择负责。收到请求后先读直接相关的代码、配置与规则，依**不确定性与耦合度**选路径，不让用户自选模式，也不按代码行数机械切分。只读问答不建事项文档。

## 判断维度

| 维度 | 核实事实 | 路由动作 |
| --- | --- | --- |
| 工作性质 | 局部修复、功能变更、探索原型、异常排查或续改 | 选择直通、`Spec Gate`、受控 `Spike`、诊断或原事项 Delta 续改 |
| 业务与体感确定性 | 根本矛盾、可观察行为、UI 体感与 `AC` 是否清晰 | 有业务分叉先一次性轻澄清；UI/技术高度未知先走隔离 `Spike` |
| 模块与契约 | 跨模块依赖、数据唯一写入者与接口边界 | 跨模块或多规则耦合时贯通起草 `spec.md` 并后台完成独立四项审查 |
| 状态与副作用 | 持久化、并发、事务清理、幂等、外部写 | 明确异常优先级、幂等保护与未知外部写防重放 |
| 风险与可逆性 | 支付、权限、删数据、大范围共享逻辑变更 | 执行前确认具体范围，完成后安排独立角色验证 |

## 路径选择

首次修改前先核对上述事实：既有契约内明确局部小修 `0` 门禁直通；意图明确事项（含复杂需求）在后台完成规格与审查闭环后仅发起 **1 次 `Spec Gate`**。

| 路径 | 适用条件与推进方式 | 文档与验证要求 |
| --- | --- | --- |
| **明确局部修改** | 目标、方案、边界明确且低风险：定位 → 最小修改 → 相关回归 → 简短返回 | 零建档、零派发，不跑无关全量测试 |
| **常规需求** | 局部业务或行为变更：先查代码（有分叉则合并轻澄清）→ `Spec Gate` 1 次确认 → 实施 → 自验 | 对话短稿或仅维护唯一控制面 `task.md` |
| **复杂需求** | 多组规则、跨模块数据/接口/状态契约：**单次贯通起草完整 `spec.md`（§1+§2）** → **后台先过 1 次异体独立四项审查** → `Spec Gate` 1 次确认 → 静音巡航 → 独立对抗验收（仅超大模糊范围或复杂多角色领域建模时才先专派 `product` / 锁 `pending_req_approval`） | 按 [文档分工](documents.md#按复杂度选择文档) 维护 `task.md + spec.md + verification.md`，满足 [完成门槛](execution-contract.md#实施与完成门槛) |
| **受控 `Spike` 探索** | UI 交互体感或高不确定技术选型需先看可运行原型才能敲定 `AC`：显式隔离路径交付最小原型收敛方向 → 转入 `Spec Gate` 补正式契约与验证 | 严禁触碰高危/非幂等写，严禁将纯原型标为 `verified` |
| **Bug/技术异常** | 偏离预期或测试失败：调用链取证 → 复现 RED → 根因推导 → 最小修复 GREEN → 回归 | 原因未知先同角色诊断；改业务预期或跨模块契约时补 `Spec Gate` |

状态性设计（持久化、并发、事务清理、权限转换或跨入口契约）在发起 `Spec Gate` 前必须完成独立四项对齐审查，单一服务或改动文件少不能作为免审依据。

## 专长与按需派发（防串行冷启动）

角色代表专业职责而非强制串行流水线：**业务意图已清晰时遵循“合一贯通起草、异体独立审查”**——由主会话或单个 `development` 子角色一次性贯通起草 `spec.md`（§1 目标与 `F/AC` + §2 `Contract-First` 架构与 `T1..Tn`），仅派发 **1 个**未参与起草的独立 `testing` 会话做四项审查（禁止为拼同一份 `spec.md` 机械串行拉起 `product → development → testing` 三次冷启动）；仅存在重大业务分叉或多角色领域状态建模时才专派 `product` 先行收敛。独立审查与最终独立验收必须由**未参与该稿起草或代码实现的独立上下文**承担（见 [宿主适配](host-adapters.md#业务派发与降级路径) 与 [最小派发](handoff.md)）。

## 路径切换

- **局部/探索转正式规格**：发现跨模块契约冲突或受控 `Spike` 已收敛方向时，补齐受影响 `spec.md` 与独立审查后发起 `Spec Gate`，不重问已决项。
- **Bug 转契约变更**：根因需调整模块契约或外部行为时，仅对受影响规格请求确认。
- **同事项续改**：按 [Delta 差量规范](documents.md#delta-差量续改与归档) 就地更新，不建 `v2/v3` 目录。
