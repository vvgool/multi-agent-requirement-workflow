## 目标

让现有任务列表的使用者按完成状态查看任务，切换后立即得到对应任务或明确的空态提示。

## 范围与非目标

包含三个筛选项（全部、未完成、已完成）、默认选择、即时筛选、空态和刷新后复位的行为定义。本轮仅需求分析和验收标准编写，不实现代码。

不包含任务状态修改、筛选持久化、网络请求及生产发布。

## 业务规则与约束

以下规则均来自 input.md 的预设场景，不构成用户审批：

- R-001：任务只有未完成、已完成两种状态；筛选项为全部、未完成、已完成。
- R-002：初次打开任务列表默认选择全部，显示列表中的全部任务。
- R-003：切换到未完成或已完成时立即显示对应状态任务；切回全部时立即显示全部任务，不额外提交筛选操作。
- R-004：当前筛选没有匹配任务时显示准确文案“暂无任务”。
- R-005：切换筛选只影响可见任务，不修改任务状态。
- R-006：刷新页面后筛选恢复全部，不记忆刷新前的选择。
- R-007：本轮不做持久化、网络请求和代码实现；目标项目适用 AGENTS.md 也仅允许需求分析。

筛选控件的具体外观与布局未作指定，可在后续获准实现时自行设计，不影响本稿的状态匹配规则。

## 验收标准

以下为后续行为验收定义，本轮未执行业务实现或行为测试。

- AC-001（R-001、R-002）：前置：列表含未完成任务 A 和已完成任务 B。操作：初次打开任务列表。结果：可选择全部、未完成、已完成三个筛选项；当前选择全部，A 和 B 均可见。
- AC-002（R-003）：前置：列表含未完成任务 A 和已完成任务 B，当前选择全部。操作：选择未完成。结果：立即只显示 A，不显示 B，无须再次提交筛选。
- AC-003（R-003）：前置：列表含未完成任务 A 和已完成任务 B，当前选择未完成。操作：选择已完成。结果：立即只显示 B，不显示 A，无须再次提交筛选。
- AC-004（R-003）：前置：列表含未完成任务 A 和已完成任务 B，当前选择任一状态筛选。操作：选择全部。结果：A 和 B 立即均可见。
- AC-005（R-004）：前置：分别准备空列表、仅含已完成任务的列表、仅含未完成任务的列表。操作：依次对三个列表选择全部、未完成、已完成。结果：三个场景均无匹配任务，均显示“暂无任务”，且不显示不匹配的任务。
- AC-006（R-005）：前置：列表含未完成任务 A 和已完成任务 B，记录其原状态。操作：依次切换未完成、已完成、全部。结果：A 仍为未完成、B 仍为已完成；切回全部后两者均可见。
- AC-007（R-006）：前置：列表含两个状态的任务，分别选择未完成和已完成作为独立场景。操作：在各场景刷新页面。结果：每次刷新后选择全部，显示刷新后列表数据中的全部任务，不恢复刷新前的筛选选择。
