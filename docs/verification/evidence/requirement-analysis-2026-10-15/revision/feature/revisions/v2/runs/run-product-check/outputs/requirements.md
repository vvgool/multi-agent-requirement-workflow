## 目标与边界

本地购物车金额展示中，保持小计原值展示，将免运费门槛调整到 20000 分。本轮只生成供评审的文稿，不实施代码。输入限定整数分，不新增非整数处理规则；支付、登录、网络、配置后台及账户系统不在范围内。

## 规则与约束

- 非负整数分小计显示其数值，不改变购物车小计。依据：v1 AC-001 与 v2 继承要求。
- 非负小计低于 20000 分显示运费 1000 分，大于等于 20000 分显示运费 0 分。依据：v2 唯一变更。
- 负整数分小计显示“金额无效”，不显示运费。负数错误优先于合法金额的运费规则。依据：v1 AC-003 与 v2 继承要求。
- 仅本地整数分金额展示，不增加支付、后台、账户或网络。依据：项目规则与 v1 非目标。

## 验收标准

| 编号 | 前置条件与操作 | 可观察结果 |
| --- | --- | --- |
| AC-001 | 购物车小计为非负整数分，分别以 0、10000、19999、20000、20001 分触发金额展示，核对前后小计。 | 显示对应小计数值，购物车小计保持输入原值。 |
| AC-003 | 购物车小计分别为 -1、-10000 分，触发金额展示。 | 显示“金额无效”，不显示运费。 |
| AC-004 | 非负整数分小计分别为 0、9999、10000、19999、20000、20001 分，触发金额展示。 | 前四种小计均显示运费 1000 分；20000、20001 分均显示运费 0 分。 |
