## 目标与边界

调用方需要把非负整数分转换为可直接比较的元字符串。提供 Python 函数 format_amount(cents)，固定两位小数，保持任意大整数的精度。

本轮包含有效输入格式化、负整数拒绝、非整数拒绝。使用 Python 标准库，项目没有历史实现。不包含货币换算、舍入、支付、账户、外部接口、UI、CLI、网络、服务或新增依赖。本隔离项目不承载生产业务。

## 规则与约束

以下规则均来自 input.md，属拟提交用户评审的业务要求，不代表已经获得开发批准：

1. 非负整数以分为单位，输出以元为单位的字符串，必须有小数点及两位小数；不含货币符号和千位分隔符。
2. 采用整数计算，不通过浮点转换造成精度损失；大整数也必须精确。
3. 负整数抛出 ValueError。
4. 非整数抛出 TypeError，包括字符串、浮点数、None 和 bool；不自动转换。负浮点数仍属于非整数，应抛 TypeError。
5. 错误消息文本不受业务约束；模块路径及具体技术组织由后续开发决定。
6. 本轮只输出产品文稿。协调层展示 v1 并取得用户明确确认后，才允许进入开发；ready 仅为产品自评。
