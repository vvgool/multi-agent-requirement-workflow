# 隔离验证示例：整数分金额格式化

目的：用一个无外部依赖的小需求，验证协调派发→真实用户评审→开发→独立测试的状态链路。此示例尚未经用户批准；产品产物只提交评审，不能自动实施。

拟定范围：提供 Python 函数 format_amount(cents)，接收非负整数分，返回不含货币符号、无千位分隔符且固定两位小数的元字符串。例如 0→"0.00"、1→"0.01"、105→"1.05"、10000→"100.00"。整数计算，不因大整数丢失精度（例 9007199254740993→"90071992547409.93"）。负整数抛 ValueError。非整数（包括字符串、浮点数、None 及 bool）抛 TypeError，不自动转换。错误消息不作业务约束。

非目标：不处理货币换算、舍入、支付、账户、外部接口、UI 或 CLI。使用 Python 标准库实现与验证；项目无历史实现。产品按真实模板整理文稿与可验收标准；开发应后续依据批准文稿选精简文档档位及最小模块/任务；测试独立核对需求、开发基线和实现。
