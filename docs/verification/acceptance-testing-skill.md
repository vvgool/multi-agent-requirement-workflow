| 场景 | 实际结果 | 关键证据 |
| --- | --- | --- |
| 正确实现，历史用例错误 | passed | 从需求纠正 10000 边界的运费/结算预期为 0/10000，独立重测全部验收项通过，保留旧用例 |
| 实现错误且符合错误旧用例 | failed | 独立检查发现实际运费 1000、结算 11000；D-1 关联 AC-1/AC-3，提供步骤、预期、实际及证据 |
| 源码新增注释，交付摘要未变 | blocked | 接单检查发现 SHA-256 不符，未执行行为验收，三个验收项均记录未执行，等待有效基线 |

结果和原始输入归档在 [检查摘要](evidence/acceptance-testing-2026-10-15/checks.json) 所在目录；每个场景保留 task.yaml、批准需求、开发交付、历史用例、源码和当前测试输出。任务中的绝对路径来自隔离临时运行，归档不作为可直接执行的安装包；重跑时须按新位置重新绑定任务路径。前两项输出含可重跑测试脚本。

逐文件摘要检查确认任务、根状态、需求、开发资料、历史用例及业务源码未被测试角色修改；Skill 源文件保持不变。三项都只生成一份测试 Markdown 报告，产物索引使用相对路径，未残留模板占位符。
