## 目标与边界

列表使用者能够根据调用方明确提供的加载状态，看到对应的加载提示、失败提示、空结果提示或列表内容，明确当前数据呈现情况。

本轮仅整理需求文稿与验收标准，不实施代码。功能范围为既有列表的状态显示；不增加新按钮、网络接口、数据存储或依赖。失败提示中的“请重试”仅是固定文案，不构成新增重试按钮或重试机制的要求。

## 规则与约束

所有业务规则来自原始诉求：

1. 调用方明确提供三个状态：加载中、加载失败、加载成功；显示方不自行推断加载状态。
2. 加载中时显示固定文本“加载中”。
3. 加载失败时显示固定文本“加载失败，请重试”。
4. 加载成功且列表为空时显示固定文本“暂无数据”。
5. 加载成功且列表非空时显示列表内容。
6. 上述显示互斥：只有成功且非空时显示列表内容；加载中、失败和成功空列表时均不显示列表内容或其他状态提示。状态改变后按新状态呈现，避免残留上一个状态的内容。
7. 不额外定义文案样式、列表布局、非法状态或数据协议；这些未被原始诉求要求。既有项目约束要求不实施业务代码、不增加依赖、不使用网络，仅在授权位置写候选文稿及结果。
